What is LangChain?
LangChain is an open-source library designed to simplify the process of building llm based applications.
It provides modular building blocks that let you create sophisticated LLM-based workflow with ease.

LangChain consists of multiple concepts
1. Model component gives use a unified interface to interact with various LLM providers.
2. Prompts component helps you enginner prompts.
3. Retriever component helps you to fetch relevant documents from the vector store.

But the biggest offering of LangChain is Chains.


What can we do with langChain?
1. Simple conventional workflows like Chatbot, Text Summarizers.
2. Multistep workflows.
3. RAG applications.
4. Basic level agents.


Challenges faced using langChain for Agentic AI:
1. Control flow complexity
   - Conditional branch
   - loops
   - jump (flow of the code going back and forth)

2. Handling State (state management)

3. Event Driven Execution (when some event occurs then the code will run but in langchain it will execute in a linear path.)

4. Fault Tolerance (if something happens to the system langchain will have to execute again but not in langGraph bcz of nodes and state management it will execute where it stopped.)

5. Human in the loop(HILT) (While creating agents some authorities are given by human but langchain follows sequential execution so its difficult to add but not in langGraph.)

6. Nested Workflow (in langchain we its difficult to flow a normal flow let alone handle the nested flow that's where langgraph comes into picture in this we create nodes and that single node can in it become a workflow and using that node or workflow we can solve the complex work flow problem.)

7. Observability (It refers to how easily you can monitor, debug, and understand what your workflow is doing at runtime.)


------------------------------------------------------------          LangGraph          ---------------------------------------------------------------

What is LangGraph?
LangGraph is an orchestration framework that enables you to build stateful, multi-step, and event-driven workflows using large language model(llm).
It's ideal for designing both single-agent and multi-agent agentic Ai applications.

Think of LangGraph as a flowchart engine for llm's --- you define the steps(nodes), how they're connected(edges), and the logic that governs the transitions. LangGraph takes care of state management, conditional branching, looping, pausing/resuming, and fault recovery --- features essential for building robust, production-grade AI systems.


When to use what?
1. Use LangChain when you're building simple, linear workflows --- like a prompt chain, summarizer, or a basic retrieval system.

2. Use LangGraph when you use case involve complex, non-linear workflows that need:
	- Conditional paths
	- Loops
	- Human in the loop(HILT)
	- Multi-agent coordination
	- Asynchronous or event-driven execution



Should we still use LangChain?
Yes, LangGraph is built on top of langChain --- it doesn't replace it.
You'll still use LangChain components like:
	- ChatModel(llm's)
	- PromptTemplate
	- Retriever
	- DocumentLoader
	- Tools, etc
LangGraph handles workflow orchestration, while langChain provide the building blocks for each step in that workflow.
